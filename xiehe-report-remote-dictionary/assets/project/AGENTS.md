# 远程字典版运行与维护规则

先读README.md、报告索引.csv及Skill。旧`xiehe-report-project`和根report.py独立保留，禁止改动或作为本版回退。

- 公共字段及取法唯一来自当前只读发布三个视图；每个顶层命令实时读取，进程内及其Power读取子进程使用一致的经核验规格，快照只作证据。
- 生成唯一走remote_monthly；旧完整D/SM解析/收集代码不是新版执行入口。本版只启用原四站NW-MONTHLY-STD-01月报，新增接入及其他报告未适配。
- 模板data_definition的活动公共ID为STD或未匹配None。previous_*和旧D/SM只追溯；不得恢复旧公共JSON、按名称猜对应或把服务器文字作为任意代码执行。
- 对应配置只保存模板绑定、命名读取器和已核验合同摘要。字段/合同漂移、混版或连接失败必须停止；不得只改摘要/开关让检查通过。
- 未匹配的Word需求保留人工待填、请求/配置或既有固定模板内容；已配置契约失效不得假装普通缺数。接口普通失败、缺月、异常0、歧义记录分别保留原因。
- 本站根配置为唯一身份来源；按Power+编码、业务年月、父子表关联、单位核验，不用创建时间替代业务月，多条不取首条/随意求和。
- 原14个模板固定位置保持内容及适用范围；不是平台实值，不跨模板或位置继承。平台当前名称/容量不替代报告命名及历史容量。
- 照片保留原字节、比例及水印，核验来源、站月、下载凭证与文件摘要；冲突照片用当次Skill外审核记录排除，原图和原因保留，不写入全局配置。
- 所有证据、DOCX、PNG、Case与临时连接配置在Skill外；凭据不进入日志/Git/安装包，测试后关闭本次隧道。
- 修改后运行report-remote.py test/check及相关实查，生成后实际查看全部最终PNG再review；配置或图文摘要变化使旧review失效。待填版版式通过不等于数据齐全或业务批准。
- 分发仅用本Skill自己的distribution-files.json白名单，验证独立解压运行；原图/原响应不覆盖，旧Skill修改前后摘要须一致。
