# 远程月报取值规则

本版只按服务器当前发布及已实现的命名读取器取数。模板保持90个Word位置、显示单位、命名角色、循环结构和14个已批准固定位置；未匹配公共定义不伪造ID或平台取法。

输入站点/年月后，核对根身份与月报关联、拉取一个当前发布、验证STD及合同摘要、查询Power+并保存证据。正文三项结算电量按本次自然月唯一父/子单读取并换成万kWh；台账逐月F054显示kWh。年度累计只有1月至报告月全部有效才计算；缺月和异常0保留缺项。

名字来自本站对应封面/简称/正文配置，年月来自请求。当前档案带采集时间列附页，不覆盖历史容量。原模板14固定位置不查平台：取证进展/票备注留空、四票不合格数0、隐患表一行；固定内容不证明当期工作或平台实值。

照片按同一结算子表取得，保留字节/水印/比例、来源响应和下载凭证。实际看图后，站名/日期冲突用当次图片审核JSON排除，再重新生成；不通过旧图补槽。未匹配现场检查来源保持缺项。

其他人工、工作记录、容量、附件复算及尚未接通的计算保持明确待填。缺少发布取法或语义范围的已对应字段不自动启用。本版不调用原完整D/SM字段解析链；旧字段引用仅在previous_*追溯，运行计划与实值来源使用STD。

交付DOCX、原始查询证据、缺项说明和最终PNG。逐页查看并review后只标draft_ready，正式业务批准另行记录。协议和变更边界见[服务器适配说明](../../references/server-adapter.md)。
