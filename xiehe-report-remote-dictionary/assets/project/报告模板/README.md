# 报告模板库

> 远程字典版说明（2026-09-11）：本版通过remote_monthly使用已核验STD契约生成原四站月报待填版；当前发布须实际check。下文保留的旧D/SM、接口及接入记录仅作历史规则参考，不驱动新版查询，也不代表其他报告已接通。活动绑定见模板的远程字段对应.json和本次运行计划，见[字典状态与边界](../数据字典/README.md)。

按项目报告场景分为计划、专项、消缺、突发四个服务大类。分类依据是用户于2026年9月9日确认的项目组织方式，不等同于已核实的Power+工单分类。

| 服务大类 | 当前报告 | 能力 |
|---|---|---|
| [计划](计划/README.md) | [运维月报](计划/运维月报/README.md) | 保留四站共用模板；须先通过远程字典兼容检查 |
| [专项](专项/README.md) | [定检报告](专项/定检报告/README.md)、[组件清洗报告](专项/组件清洗报告/README.md) | 已有模板与定义，未接通当期自动填充 |
| [消缺](消缺/README.md) | 尚未定义 | 仅分类入口 |
| [突发](突发/README.md) | 尚未定义 | 仅分类入口 |

[分类索引](分类索引.csv)登记四类入口；[报告索引](../报告索引.csv)登记实际报告及其服务大类、关联表和规则入口。空分类不登记虚构的报告或模板。

每种报告下的`模板/<模板编号>/`保存唯一共用Word、字段位置和填写规则，`模板电站索引.csv`关联电站，`电站/<本站>/`只保存本报告适配；唯一身份仍在项目根[电站](../电站/README.md)。报告内部的`数据字典/字段字典.json`是Word填写位置定义，公共业务数据定义与取法只从服务器读取，见[远程字典说明](../数据字典/README.md)。

新增报告或模板先按[接入规则](../电站与模板接入规则.md)核验。本轮只调整报告组织与路径，未新增业务报告能力或改变新电站流程。
