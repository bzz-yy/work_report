本目录已获用户授权按两套主模板构建。先读README.md、模板电站索引.csv和本站AGENTS.md，再读所选模板旁的通用取值规则.json及本站配置。第二版字段取数配置引用模板通用规则，填写规则只保留本站观察/确认/差异，定位程序会合并后返回有效规则。

## 选择规则

- DJ-01为结果版，DJ-02为检查标准＋结果版。济柴必须明确版本，未知或冲突不自动选择。
- 一站只有一个当前登记版本时可以定位，但不把单个2026-H1样本当作永久合同规则。
- 详细版必须选择本站条款文件。新期间条款适用性未确认时，不自动组合历史标准。
- 设备章节、两票和签字顺序由选定profile控制，不能据页数或字段相似度临时删改。

## 字段与能力边界

- 主模板的原生内容控件标签是模块边界，修改时同步映射。
- J035—J039须连同module_id和record_id解释，禁止在全部设备表全局替换为同一值。
- 检查结果可能按设备编号或部件/检查项记录，依本站实际口径，不用设备台数强行决定行数。
- 已实现定位和空白结构组合，当前没有完整的真实取数与最终报告填充器。按实际完成程度报告状态。
- 外部来源未配置时保留待补，不用样例数值、旧照片、旧签名或猜测的字段编号代替。

## 维护规则

主模板更改须更新版本、摘要和映射，并验证五种组合。条款变更单独版本化并保留来源与适用范围。新增记录行不创建新主模板；新增固定模块/列才评估模板升级。

不复制原始报告到本目录，保留来源路径及摘要。用户原件只读。组件清洗有独立的规则草案入口，不套用定检字段或条款。

本目录的字典补充清单.json、取值规则与字典补充清单.md列出42项定义的字典候选、Power+核验及待补内容。模板DJ-01启用39项，DJ-02最多42项；关闭两票仍遵守本站profile。候选映射不自动升级为生产取数成功。
