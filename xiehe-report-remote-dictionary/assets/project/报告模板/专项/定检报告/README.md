## 主模板与电站关系

| 模板 | 电站 | 本站配置差异 |
|---|---|---|
| DJ-01 定检结果版 | 济柴、保龄宝、伊利 | 结果章节分别选择5类、2类、4类设备 |
| DJ-02 检查标准＋结果版 | 迈大、济柴详细版 | MD/JC条款版本分别保留；济柴含两票、迈大不含；签字顺序不同 |

这是2套主模板加不同配置，不是认定五份原件完全同版。济柴必须明确结果版或详细版，不能只凭电站名称猜选。

两版都包含基本信息、工作量、缺陷处理、整改计划和结论。核心区别是：DJ-01记录“检查情况、照片、处理结果”；DJ-02还列出“检查哪些项目、按什么质量标准检查”，包含高压柜、变压器、组串式逆变器、二次设备的检查标准表及其他设备要求。两票是DJ-02的可配置模块，不是每个详细版都必带。

目录已修订为可直接阅读的分级目录，带正文跳转链接和页码域。主模板展示其全部模块，按站点组合后只列实际启用模块。当前模板目录页码已按预览逐项核对；填入实际数据后须更新页码。

## AI使用顺序

1. 从根目录报告索引进入定检目录，识别电站及上半年、下半年或全年周期。
2. 查关联索引。济柴须明确结果版、详细版或模板编号。
3. 读本站AGENTS.md、电站配置、所选模板通用取值规则，再合并本站字段备注和填写证据。第二版字段取数配置按profile引用模板规则。
4. 运行脚本/resolve_report.py，得到模板、本站profile、条款文件、逐字段计划和缺项。
5. 如需检查结构，运行脚本/assemble_blank.py，实际选择设备模块、替换本站条款、处理两票和签字顺序、整理当前目录。结果仍为占位符空白结构。
6. 接入真实取数、校验、填充及成品验收后，才能交付正式报告。

使用宿主提供的Python。定位示例：`脚本/resolve_report.py --request '生成济柴2026年上半年定检详细版'`。空白结构组合示例：`脚本/assemble_blank.py --request '生成保龄宝2026年上半年定检报告' --out 新文件路径.docx`。已有输出不覆盖。

## 字段和增减行

J001—J039为共用业务字段，J040—J042为两票字段。DJ-01启用39项；DJ-02中济柴启用42项，迈大关闭两票后启用39项。字段定义数不是固定单元格数。

J035—J039在不同设备表复用，必须按“字段编号＋设备模块＋记录标识”定位，不能全局填成同一设备值。工作量、缺陷、结果及两票按真实记录增减行。样本既有按设备编号，也有按部件/检查项记录，不能用设备台数强行决定结果行数。

检查标准按受控条款版本选择，不能让AI自由生成或混合两站条文。新期间没有确认适用性时，详细版组合会停止，不自动沿用2026-H1条款。
