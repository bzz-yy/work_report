## 选择与维护

济柴两份同期间原件必须区分：未明确结果版或详细版时停止定位并要求明确，不能按修改日期猜。

- 新增检查对象、缺陷或工作量记录：在所属表内增加行，复用已有列定义；结果字段必须带设备模块和记录标识。
- 新增设备种类：先核实是否属于已有模块；不属于时升级模板模块及配置，不把数据行误当章节。
- 检查标准是受控条款版本，不能随意改写或只按字数相似合并。本站版本应有适用周期和业务确认。
- 两票及签字顺序来自所选版本；调换签字顺序不得交换签字人的角色。历史签名和照片不可重用为当期来源。
- 结论、正常/合格、遗留问题无等均需当期证据，不能在空模板预置。
- 不用设备数量强行生成等量检查结果行，不用本次样本行数作为固定上限。
- 本站字段继承模板通用规则；填写规则.json保留本站观察、确认及差异。

## 本站特殊问题
- 原目录存在SVG条目与正文不对应及编号跳号；组装目录仅按实际启用模块产生。
- 高压标准与迈大相差35kV条目及互感器表述，必须选JC条款版本。

## 能力边界

当前可以定位模板、读取本站规则并组装本站版本的空白结构。实际外部字典、Power+、独立照片和签认来源尚未绑定；最终报告取数、填充和业务验收不能据此视为已经完成。

## 文件职责

- 电站配置.json：身份及各模板的设备、条款、两票、签字顺序。
- 字段取数配置.json：按模板版本引用通用规则，并保留本站参数、字段备注和特例。
- 填写规则.json：本站观察、确认、证据与差异；通用字段和循环规则继承所选模板。
- 维护证据.json：当前原件记录数量、设备标签和特殊问题。
- 本地资料索引.json：按模板版本及报告期间绑定唯一历史原件，不复制原件。
- 需填写字段.csv：便于业务人员查看的字段清单。
