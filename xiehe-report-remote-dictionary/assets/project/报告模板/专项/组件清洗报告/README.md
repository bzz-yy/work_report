## 模板内容与使用

模板保留封面流程、清洗原则及概述、进厂施工手续、安全资料、现场和前后对照照片、视频、验收附件、效率分析。空白版4页、7张表、33类字段；照片和数据记录按本次实际数量扩展，模板显示行数不是上限。

- [填写说明及字段表](模板/QX-01/填写说明.md)：占位符、照片扩组、数据扩行、汇总子键和待确认事项。
- [通用取值规则](模板/QX-01/通用取值规则.json)：唯一的模板字段、单位、适用及填写规则入口。
- [模板字段映射](模板/QX-01/模板字段映射.json)：版本、摘要及每个Word位置。
- [模板电站索引](模板电站索引.csv)：三站关联及保龄宝缺样状态；实际状态以本站JSON为准。
- [验收附件版本索引](验收附件版本索引.json)：伊利两份历史PDF分别登记；本次未重制独立验收单Word。

复制模板后，替换整个占位内容（编号及“待填”等提示），不要将提示文字留在成品中。每次填写须核对本站、本次作业日期、次数和确认版本。未取得照片与签认文件时保留槽位，不能复制历史资料。

历史清洗原则中的4%触发、7天间隔及年度次数未被确认为三站永久规则，已改为受控文字待填；容量不自动等于全站装机，效率表的汇总和变化说明不预置公式或零值。来源和查询方法由服务器公共字典发布，当前未核验的清洗取数能力不作为可执行接口。

伊利两种验收单的概况字段、场景说明、签字栏不同，须分开选择当期附件；这不影响主报告共用。其他站主报告的验收附件槽不能证明采用伊利的任一版本。
