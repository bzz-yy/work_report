# 组件清洗主报告模板填写说明

> 远程字典版说明（2026-09-11）：本版通过remote_monthly使用已核验STD契约生成原四站月报待填版；当前发布须实际check。下文保留的旧D/SM、接口及接入记录仅作历史规则参考，不驱动新版查询，也不代表其他报告已接通。活动绑定见模板的远程字段对应.json和本次运行计划，见[字典状态与边界](../../../../../数据字典/README.md)。

QX-01，版本1.0。由六份主报告共同结构提取，适用济柴、迈大、伊利；保龄宝缺样本待核。Word为空白模板，本次不执行线上取数。

## 填写方法

1. 复制Word后填写，保留空模板原件。先确认电站、年份、清洗次数、实际起止时间及有效版本。
2. 花括号内Q编号用于稳定定位；人工填写时替换编号及旁边提示文字，程序填写时按字段映射XPath替换整个槽位内容。不得仅替换编号后把“待填”留在正文。
3. 本次照片和附件取自本次任务，插入后验证可打开。照片保持原比例，不裁剪水印和必要信息；签名不复用。
4. 填完后更新Word页码域，逐页检查表格、图片、附页与页码。当前页码设置为打开自动更新。

## 重复记录与汇总

- 现场照片表初始两张：Q016[1]、Q016[2]。增加照片时复制图片行与说明行，并更新记录序号和图注。
- 前后照片表初始一组：图片行含Q018[1]、Q019[1]，下方日期行两侧共用Q017[1]。增加日期记录须复制完整两行，保持同组同日期及前后对应。
- 效率分析初始清洗前、后各一条。清洗前数据行Q022—Q026，清洗后Q027—Q031；复制数据行后更新序号，禁止把汇总行当数据行。日期数不固定为5，照片也不默认每天必须一组。
- Q032的B表示清洗前、A表示清洗后；E为电量、H为满发小时、R为辐照、PR为系统效率。各项分别填写，不能把一项值覆盖全部汇总格。
- Q005分trigger（触发条件与依据）和frequency（频次与覆盖范围）两个位置。历史文字不自动适用于新合同或新期间。

## 单位与业务边界

清洗容量原栏为MW，仅保留原显示标签；须确认指本次覆盖容量还是全站容量，不据数值把MWp转换为MW。日发电量栏为kWh，满发小时为h，辐照为MJ/m²，系统效率为%。
Q032无预置求和或平均公式；取样窗口、有效辐照、装机口径及汇总方法未确认时保留待填。Q033不预置“效率提升”，结果可能升高或降低，需区分百分比相对变化和百分点差。
当期数据缺失不填0、无、合格、已完成；同一人员、设备或原则反复出现不构成永久常量。平台来源及查询方法尚未接通，不能用历史数值假装本次查询。
