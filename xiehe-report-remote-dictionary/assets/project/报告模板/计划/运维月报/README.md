# 运维月报

本服务器版使用四站共享Word模板NW-MONTHLY-STD-01，保留90个填写位置、循环表、显示精度、本站命名和14个已批准固定位置。当前生成走`remote_monthly`，不调用原完整D/SM解析链。

## 数据与配置

- `模板电站索引.csv`和本站`电站配置.json`关联根站点身份及共用模板。
- `模板/NW-MONTHLY-STD-01/模板字段映射.json`记录Word位置；`通用取值规则.json`的活动公共定义为STD或未匹配None，previous_*仅追溯。
- `远程字段对应.json`记录14个明确STD对应及命名读取器/合同摘要；公共定义与取法每次实时读服务器，不在本地存第二份公共字典。
- 本版已启用当前档案身份、结算三项电量和结算子表抄表照片；结算工单/期间用于查询核验。容量、工作记录、计划、故障合计、附件复算和未匹配来源保持待填或未启用，不沿用旧版来源补值。

F004/F005/F006按当月结算值显示万kWh，F054按年内各月独立取值显示kWh；F011及台账累计仅在月份完整且值有效时计算。原始0、缺月、歧义和接口失败分别保留原因。

## 生成与验收

从Skill入口执行`generate --request '生成济南迈大2026年8月运维月报' --out 新目录`，会实时拉取、核验、查询、填Word并渲染。具体环境和参数见[Skill](../../../../../SKILL.md)。未知站/模板先报告接入需要，本版不提供旧onboard写入流程。

14个模板固定位置按原批准执行：取证进展及票备注有意空白，四票不合格数0，隐患表固定一行；它们不代表平台实值。其余人工数据不抄旧报告。完整固定内容说明保留在模板目录。

照片必须核原图站名、日期、关联和摘要，冲突图片以本次Skill外审核记录排除，原图不修改。输出保存字典快照、执行目录证据、平台响应、照片凭证、DOCX、PNG和缺项说明；实际查看全部PNG后再review。待填版通过不等于数据完整或业务正式批准。

本文之外保留的本站观察和历史D/SM说明用于解释原模板语义，不是新版执行入口。当前来源边界见[远程适配说明](../../../../../references/server-adapter.md)。
