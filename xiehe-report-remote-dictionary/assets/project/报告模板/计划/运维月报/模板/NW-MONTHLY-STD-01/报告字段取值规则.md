# 月报字段取值规则（NW-MONTHLY-STD-01）

> 远程字典版说明（2026-09-11）：本版通过remote_monthly使用已核验STD契约生成原四站月报待填版；当前发布须实际check。下文保留的旧D/SM、接口及接入记录仅作历史规则参考，不驱动新版查询，也不代表其他报告已接通。活动绑定见模板的远程字段对应.json和本次运行计划，见[字典状态与边界](../../../../../数据字典/README.md)。

规则版本以[通用取值规则JSON](通用取值规则.json)为准，公共字典定义不因模板固定而改变。本页是阅读说明，执行以[通用取值规则JSON](通用取值规则.json)为准。90项已经逐项研究并交叉核验，代表每项有业务含义、查找或计算路径及缺项规则；不代表90项输入都已取齐，也不代表所有查找方法均已自动填充。

档案和月台账可以是合法来源，不要求每项都有实时测点。月电量、月辐照是期间量；容量、工具和证书有生效时间；人员是指定统计口径下的状态；计划与工作是记录集合；累计和比例由输入计算。名称相近或连续多月相同都不能替代业务判断。

## 来源路径与当前自动执行范围

- **结算电量**：按本站、结算月份及自然月起止选择唯一主工单，详情r_id关联唯一结算子表。[来源采用核验](来源采用核验.json)支持F004/F005/F006正文kWh转万kWh，最多6位小数；F054逐月kWh最多1位。真实冲突和未核0继续保留。
- **计量附件**：字典方法 `power.electricitybill.attachment_meter.v1` 复用上述子表的 `at_messages_photos`。有限解析契约（历史依据，保存在项目留档中）明确必需计量表、站月、表号、方向、倍率及公式检查。当前仅迈大2/3月附件四项电量和其中1月站用业务行获准。F005/F006可补充选源，F007/F058接站用；F004/F054继续使用已选结算总量，附件总量用于校核。
- **现场计划**：`power.plan.triggers.v1` 查计划下发实例、详情及同站关联工单。[本站计划政策](../../电站/XNY086_济南迈大/字段取数配置.json)仅批准迈大2026-06安全管理“其他计划”，一条源计划一行填F060，F059派生序号。下月计划必须有报告期末内容版本，目前只保存候选。
- **实际工作和图片**：`power.other_work.executions.v1` 按实际处理日期接入安全管理记录，F065/F067取分类及内容，F064按记录编号。这不能证明所有工种工作齐备。F090区分检查照与抄表照，原图、比例和水印保留，多图扩行。
- **其余资料和状态**：除已批准模板固定的14个位置外，人员、两票、培训、风险、隐患和工具按下表逐项查找、匹配。找到文件只证明来源存在；对象未对应、当期输入未核或执行器尚未支持的部分保留待填。

同站同月结算查询在本次生成中复用。从二月附件查到一月台账时，容器结算月与行业务月分别保存；二月电量不能进入一月报告。同一月跨附件同值作佐证、不相加，冲突不选首个；原API填0不被改写。

## 已配置的14条计算规则

下表列JSON实际存在的计算槽位，不包括附件内部表底运算、序号及仍待接入的候选汇总。仅迈大登记采用范围：能源相关规则为2026-01至07，票据合格率为2026-02至07。其他三站尚未采用这些新增计算规则。采用算法仍要求每次输入齐全、同站同期间同口径。

| 计算字段/位置 | 输入与运算 | 单位及取整先后 | 缺项处理 |
|---|---|---|---|
| F008正文 | 引用当月F057 | H→小时；复用已取2位的当月小时，最多2位去尾零 | 缺当月F057待填 |
| F011正文 | Σ本年各月F054来源原值，再×0.0001 | kWh→万kWh；先原值求和，再最多6位去尾零 | 缺任一月真实原值，累计待填 |
| F012正文 | Σ本年各月F057 | 小时；先各月2位，再相加，累计最多2位 | 缺月待填，不改用年电量÷容量 |
| F013正文 | F012÷F014×100 | 小时/小时→%；最多2位，最终仅一个百分号 | 缺目标或累计值待填；分母0不计算 |
| F034合格率 | F032÷F031×100；校验F032+F033=F031 | 票数为非负整数张；比率为%；当前仅整数结果或确认0票的/ | 缺同集合/完整评价待填；非整数精度未核 |
| F039合格率 | F037÷F036×100；校验F037+F038=F036 | 同上 | 同上 |
| F044合格率 | F042÷F041×100；校验F042+F043=F041 | 同上 | 同上 |
| F049合格率 | F047÷F046×100；校验F047+F048=F046 | 同上 | 同上 |
| F054累计行 | Σ本年各月F054来源原值 | kWh；不加已舍入的月显示值；累计最多6位 | 缺月不输出部分和 |
| F055累计行 | Σ本年各月F055已核验值 | kWh；同一核减口径求和，最多6位 | 缺月、未知零值或不同损失范围待填 |
| F056累计行 | Σ本年各月F056已核验辐照能量 | 保留原模板标签KW-h/m²；同单位同辐射面求和，最多6位 | 缺月、单位或测点口径未核待填 |
| F057逐月行 | 月F054来源kWh÷月F053有效MWp×0.001 | H（小时）；每月先取2位并去尾零 | 缺电量/容量待填；容量0不计算 |
| F057累计行 | Σ各月已取2位的F057 | H；先月取整，再累计，最多2位 | 缺月待填，不改用年总电量÷容量 |
| F058累计行 | Σ本年各月F058来源原值 | kWh；原始站用月量求和，再最多6位 | 缺月待填，同月多附件只计一次 |

数值舍入采用JSON规定的四舍五入（half_up）。票率配置虽有2位显示参数，`fractional_precision=pending` 仍会阻止未经核验的非整数结果。F056原文单位拼写属于兼容显示，不能据该标签认定任何上游辐射值可用。累计行单列，缺月不补0；填写前重新核验输入原值、单位、文件与当次响应。

## 缺项与变更处理
