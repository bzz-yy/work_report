## 先区分增加行与增加字段

- 新增一件工具、一项计划、一条工作记录：在对应循环表里增加记录行，继续使用原有字段编号。
- 删除/退出一项记录：须有当期清单或业务依据，不能因上月不再出现就推定资产报废。
- 新增栏目或改变固定章节：修改共用模板、字段字典和映射并升级版本；不要只在本站配置私加一个未定义字段。

### 工器具表的明确处理方式

表10使用F079—F086：序号、编号、名称、型号与规格、制造厂家、试验日期、试验结果、下次检验时间。字段编号对应列，并不对应某一件固定工具。按编号匹配工具，同名不同编号的工具不能合并。

本站跨月证据：
- 2026-03 → 2026-04：2个共同编号的字段变化，例如FBSPQ2-10kV-YDQ-01：试验日期 2025.05.14 → 2026.04.14；下次检验时间 2026.05.13 → 2027.04.13。
- 2026-04 → 2026-05：10个共同编号的字段变化，例如FBSPQ2-10kV-JYST-01：试验日期 2025.11.14 → 2026.05.19；下次检验时间 2026.05.13 → 2026.11.18。

维护规则：允许有依据地增减行；试验日期、结果、下检日期随真实检验记录更新，不能统一硬加半年或一年。新增/退出的原因、统计范围及共享工具归属仍待业务确认。

## 逐章节填写细则

### 1.2 发电量台账

按当年截至报告月的实际台账列月记录，累计行单列；新月份增加记录，不是新增字段。历史月份修订需记录修订前后值及依据；不得生成未来月份的实际值。

缺少月份不能补0；列出缺项。累计行不是额外月份。

### 2.1 月度作业计划

按本月实际计划增减行；同一行的工作内容、风险、等级和措施成组填写。新增工作类型仍用现有5列，不能因模板曾列5行就填满5行。

工作内容空白的备用行不算计划；其他列有实质信息而工作内容空白须复核。

### 2.2 本月工作总结

一项有实际工作内容的记录对应一行。仅有合并继承的“日常运维”、无工作内容的末行是备用行。单层类别使用现有两级类别区域并横向合并；同一一级类别下的多条工作可纵向合并，合并不得吞掉不同工作内容。

不能根据上月有该事项就默认本月已完成。缺工作内容且有二级类别/其他实质信息的记录应标待核。

### 2.3 下月工作计划

按报告月的下一月计划增减行，跨年时年份加1；不把本月总结当成下月计划。与同一表的需协助事项分两段处理。

无事项和未取得计划必须区分；不保留只有序号的备用行作为真实计划。

### 2.3 需协助事项

按待协助事项增减行；本批六个月均填“无”，只证明样本没有列具体事项，不证明永远没有事项。

已核实无事项可显示一行“无”，语义记录数为0；未取得资料要待补，不能写无。

### 3.3 发电损失明细

每个实际损失事件一行；只有损失数字、日期容量原因均为/的记录仍须保留并列为信息不完整，不能删成无事件。各类损失可能不同口径，不把明细总和直接等同受累损失总数。

全行/或无是无明细占位，不算一个事件；零值保留，不能把缺值变成0。合计行与事件数据行分开。

### 4.4 隐患排查与治理

本模板F076—F078按用户批准固定展示一行：“1｜站场火灾隐患｜及时清理扑灭火源及清理可燃易燃物”。所有同模板既有/新站持续采用，不查询该位置当期隐患源；它是模板内容，不证明当期已发现隐患或完成措施。修改这项内容须修订模板规则并重新试生成、逐页检查。

### 4.5 安全工器具、仪器仪表定期检测

按本站报告期适用工器具清单逐件增减行，一件一个编号；同名不同编号保留多行。新工具沿用F079—F086八列，不创建新字段。数量、序号、名称重复不能作为工具主键；缺编号或重复编号须核查。

历史记录减少不等于工具已报废。必须核实调拨、报废、漏填或统计范围变化；空清单且没有明确无设备证据时不得直接清空。

### 正文指标和电站档案

封面F001、概况简称F051、1.1名称F087读取本站相应配置；F002/F003同步所有年月位置。装机容量F015、年度可研小时F014按有效档案/年度配置读取。正文与表格重复出现的同一指标共用已核实值；不同单位先记录原值和换算，不能用单纯字符串判错。F013显示值只保留一个百分号。

F010与受累电量说明F088互相核对，未取到不写无受累电量。F089合计填写位置仍待确认；不同类型损失的明细合计不一定等于正文受累损失，不擅自套公式。

### 分析培训人员及票据

运行分析F016、故障处理F017、培训F021按当期实际记录写，可增加文字段落；不把模板示例或季节常识当成本月已完成事实。

本站低压和高压应取/已取人数在2月均为3/3，3—7月均为5/5；调度受令应取3变5、已取一直0。四站同步变化，统计范围需确认。三个取证进展F024/F027/F030和四个票种备注F035/F040/F045/F050已批准跟随模板固定为空，不查当期源、不标待填、不列缺项；字段位置保留。

两票F031—F050中，F033/F038/F043/F048按模板固定0，四票备注固定空白；其余位置继续按实际来源或已采用计算规则。取数日期口径、跨月/取消票处理、零票合格率规则待业务确认，不自动将/变为0或100%，也不把模板0当作实际票据评价依据。

### 照片附件与版式

F090当前8个槽位。图片按本站、当期和实际作业取得，少图标缺项，多于8张需先扩展图片区域，不静默丢图。历史内嵌照片只作为比对证据，不能冒充已取得独立来源。2—4月内嵌巡检附件，5—7月未内嵌；正式交付方式及目录更新需单独确认。

## 本站文件与AI执行顺序

1. 电站配置.json确定本站、模板、规则入口。
2. 本文件解释维护方法；模板通用取值规则按90个字段和8组循环表定义方法；填写规则.json保留本站证据与差异。
3. 字段取数配置.json按模板关联通用规则并提供参数、字段备注和有生效范围的覆盖项；取数位置与填报维护规则分开。
4. 逐月维护证据.json保存六个月的有效记录、清单变化、问题及原文件位置；需要追溯时按月份查。
5. 用户已批准的14个持续固定位置唯一维护于通用规则template_fixed_content，本站直接继承同模板内容；其他站期特例仍写字段取数配置并保留确认人与生效范围，不继承其他站批准。
6. 定位器已能返回本站规则引用；最终填充器仍需按规则扩展行、恢复文字格式并检查成品，不宣称已经完整自动执行。

完整固定清单、剩余7个待确认项及F070/F071位置见[模板固定内容](../../模板/NW-MONTHLY-STD-01/固定字段二次确认.md)。此批准限所选模板位置，不因共享D延伸到其他位置或模板；模板规则修订后旧运行review证据失效。
