## 计量附件如何采用

1. 复用本次已取得的唯一结算子表，读取 `at_messages_photos`；不为每字段重查工单。只从已核验Power+文件URI下载，跨对象存储主机不转发API凭据。
2. “01发电记录单”的反向发电侧表底差乘倍率汇总总发电，正向用电侧汇总站用。“02上网记录单”两个关口反向表底差汇总上网。“05通知单”明确消纳=总发电−上网，站用另行结算。
3. [计量附件参数](计量附件参数.json)分别保存两块发电表和两块关口表的表号、倍率、允许期间。第二关口公式若引用第一块表倍率，只有两倍率相同才通过；未来倍率变化必须重新核验。
4. 不读取“03其他光伏站用电量单”的2021年示例、XNYmmmnnn或NO:xxxx。另一张《迈大站用电》有明确一月行、单位、用途和截至一月标题，是合法独立月台账，已获准采用，不强制追到一月表底。
5. 同一业务月在多附件出现先核对象和版本：同值作佐证不相加，不同值报冲突。原结算0留在原响应，不改写。只生成一月时可从获准二月容器取一月行，不能把二月电量填入一月。
6. 填写前重新读取原xlsx，核对字节摘要、政策摘要、单元格、公式、缓存差、原始值和单位；显示值碰巧相同也不能绕过原值核验。具体步骤见有限解析契约（历史依据，保存在项目留档中）。

## 人员、两票和计划口径

- 低压、高压、调度受令三证类均需本站或经确认共享班组的名册、岗位证类要求和统计时点。历史人数变化只证明样本变化，不能推出人员名单；“月末”仍是候选统计时点。
- “已完成取证”与“当前有效证”分别记录。按取得状态还是有效状态计数尚待确认，不能直接互换；应取证和已取证采用同一获准范围、时点。
- 两票需明确收票日期、作废及补票规则。主票、续页、安全交底和扫描副本先建立对应关系，不按PDF页数/登记行数计票；已执行、已终结或流程pass不是质量合格。
- 24组本站历史票种/月样本支持合格÷收票×100及完整0票显示“/”。非整数比率精度没有样本，继续待核；缺评价不能按0不合格推全合格。
- 交接包已找到5份两票扫描PDF，共146页，本轮抽查12页。可说抽查页有旧资料、未取得六月完整输入，不能断言146页全部没有六月资料。
- 六月1条已下发现场计划与5条实际处理记录各自保存。一项计划可能产生多条处理；下一月候选缺报告期末文字版本，继续待核。

## 工具对象与规格冲突

工具字段已有来源线索，不能整列笼统写“平台没有”。当前找到两组接地线证书及清单/现场影像，但管理号JDX01/JDX02到月报FBSPQ2-10kV-JDX-01/02没有直接对应。证书25 mm²与旧台账16 mm²有规格差异；不能按尾号相同匹配，也不能将三相样品当三套接地线。其余10件工具对应的2026-05-19检验证书尚未取得。

按对象保留候选、缺映射和规格冲突，不抹掉已知名称、试验日期等来源事实。先选报告期末前最近适用检验，再显示合格或不合格；不跳过新不合格选旧合格。有效证书可跨月采用。证书明确建议的2029-06-24下检日期可作对应对象候选，但不保证期间一直安全，也不自行统一加半年或一年。定位及具体问题见[本站来源指南](来源指南.json)。

## 怎样变更参数和有效期

1. 保留新来源原件、查询参数、采集时间、站点、业务期、对象ID和版本，查明替代哪个旧版本、影响哪些月份或对象。
2. 来源定义或接口/附件结构变化提交[服务器公共字典](../../../../../数据字典/README.md)维护方发布并重新核验；字段选源、模板固定内容、单位、精度、公式维护[通用模板JSON](../../模板/NW-MONTHLY-STD-01/通用取值规则.json)，不在本站复制接口代码或公式。
3. 表号/倍率、容器期、计量期及辅助业务期维护[计量附件参数](计量附件参数.json)。增加月份前必须核验该月表号、倍率、格式、站月及结果，不能只扩期间列表。
4. 公式采用范围、计划期间及限定期间特例维护[字段取数配置](字段取数配置.json)。特例有确认人、原因和明确期间；manual覆盖会停用相应自动规则，不能仅改状态强制填值。
5. 电站身份/平台编码变更在[根电站基础配置](../../../../../电站/XNY086_济南迈大/基础配置.json)保留核验证据；报告显示名由本站报告配置维护，不混用资料编号和平台编码。
6. 同步[来源指南](来源指南.json)中的缺项与定位；指南不供应旧值。更新[字段反推核验](../../模板/NW-MONTHLY-STD-01/字段反推核验.json)及摘要，执行 `report.py check`、相关回归和对应站期样例。模板规则修改后旧运行review证据失效，需重新试生成；DOCX最终须逐页查看PNG后记录review状态。
