表10的F079—F086对应八列：序号、编号、名称、型号与规格、制造厂家、试验日期、试验结果、下次检验时间。新添一件工具是新增一条这八列组成的记录，不需要创造F091等新编号。跨月按编号匹配；同名工具可有多个编号；序号只作展示。

## 其他表怎样处理

| 内容 | 处理方式 | 当前边界 |
|---|---|---|
| 年度发电台账 | 按实际月份增加行，累计行单列 | 不预填未来月实际值；历史月份更正留依据 |
| 作业计划、本月总结、下月计划 | 按当期实际工作增减行 | 备用空行不算记录；重复文案不代表当期已执行 |
| 需协助事项 | 有事项按件列；确认无事项才写无 | 六个月都写无不代表永久无需填写 |
| 损失事件 | 每个事件一行；只有数值而缺事件信息的仍保留待核 | 全/占位不是事件；合计口径和位置仍待确认 |
| 隐患 | NW-MONTHLY-STD-01按用户批准固定一行F076—F078，具体原文见模板规则 | 这是模板展示内容，不代表当期已发现隐患或完成措施；不查该位置的平台源 |
| 人员持证 | 当前3类证件、9项位置；三个取证进展按模板有意留空 | 人数仍按有效来源，不从空白进展推断人数；新增证件类别需升级字段映射 |
| 两票 | 当前4种票、20项字段；不合格数按模板固定0，备注有意留空 | 其他票字段继续原规则；固定0不能代替实际评价输入或推断合格率 |
| 培训、运行/故障分析 | 文字和段落数按实际记录变化 | 不将模板示例或季节推断当作已发生事实 |
| 照片 | 当前8个槽位 | 少图列缺项；超过8张先扩展图片版式，不能丢图 |

## 哪些已经明确 哪些仍需确认

已经明确的是样本的结构、数量、字段和清单变化，以及自动化应怎样避免错删、错并和串站。尚未明确的是每次清单变化的业务原因、工具是否片区共用、人员统计口径、检验有效性、空值填写标准等。相同内容可作候选；2026-09-10用户已明确批准14个位置在NW-MONTHLY-STD-01持续固定，其余7个候选仍待确认，见[固定内容与候选](模板/NW-MONTHLY-STD-01/固定字段二次确认.md)。同模板新站直接采用模板内容，站期特例不从其他站继承；修改模板规则后重新试生成和逐页验收。

定位器已经把本站规则带进取数计划，能找到“该站应该按哪套规则维护”。规则目前是给AI和后续填充程序使用的配置，尚不等于最终填充器已经自动执行了全部规则。

标准原件副本已从模板目录移除，外部原始文件保持不动，共用模板本体未改变。
