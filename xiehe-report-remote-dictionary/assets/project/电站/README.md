# 电站基础配置

本目录每站一份`基础配置.json`，是电站名称、别名及各数据平台编码的唯一执行来源。月报、定检和组件清洗的本站配置通过`station_ref`引用，不复制这些属性。

根[电站平台对应.json](../电站平台对应.json)保留为只读阅读索引。电站基础配置中的identity_evidence记录身份核验依据，不能把平台代码和项目资料编号混用。

报告资源按[四个服务大类](../报告模板/README.md)组织：计划下为运维月报，专项下为定检、组件清洗，消缺和突发暂未定义报告。模板选择、正式报告名称、设备模块、条款、交付要求及限定期间的数据冲突/零值核验，放在`报告模板/<服务大类>/<报告类型>/电站/<本站>/`的适配配置中；模板关联登记在该报告的`模板电站索引.csv`。该目录中的“电站”不承担第二份身份维护。

当前没有需要每站单独实现的取数脚本；各站共用CLI适配和公共数值处理代码。
