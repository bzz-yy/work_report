# 新增接入范围

当前服务器版只执行已配置的四站NW-MONTHLY-STD-01运维月报，未开放新增站、模板变体或专项报告的接入写入命令。`route`可以识别尚需接入的请求，但不会自动注册或启用。

新增接入需要先明确服务器STD字段和取法、模板位置/单位/维度、站点身份及报告适用范围，并实现相应读取器和模板适配；完成隔离检查、真实站月查询、Word逐页验收后才能启用。单纯修改配置或通过字典check不足以证明新站已接通。

本版不提供旧D/SM的onboard/init/apply/trial/activate流程，也不把旧Skill作为运行回退。原本地字典版完整接入实现独立保留，属于另一个Skill的能力。

当前生成、照片审核与交付命令见[Skill](../SKILL.md)，服务器合同变更见[适配说明](server-adapter.md)。
